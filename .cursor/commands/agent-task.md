# /agent-task

Execute a Seloma development task using the canonical framework.

1. Read `.ai/README.md`
2. Follow `.ai/workflows/task.md`
3. Load `.ai/rules/core.md`, `.ai/rules/dont-do.md`, and only the rules matching the classification
4. Use the matching agent under `.ai/agents/`
5. Discover contracts via `.ai/contracts/`
6. Implement with minimal diff
7. Run relevant typecheck/tests
8. Report using `.ai/templates/task.md`

User task follows this message.
